# Sources

* [Memphis 311 ArcGIS FeatureServer, layer 0](memphis-311-featureserver.md) - The City of Memphis 311 request map service - the only source of request data, read with query calls only, personal fields dropped at extraction.
* [Census tracts, Tennessee (BigQuery public data)](census-tracts-tennessee.md) - Census tract polygons used to assign each request to one of 221 Shelby County tracts and to draw the tract map.
* [US county boundaries (BigQuery public data)](us-counties.md) - County polygons; the Shelby County boundary decides whether a request's coordinate is valid.
